# Ruang Kecilku V2

Ruang Kecilku V2 adalah rebuild visual awal dari Teman Harian menjadi aplikasi baru yang berfokus pada tiga hal:

- Makan Hari Ini
- Mood Hari Ini
- Cerita Hari Ini

## Arah visual
- Tema hangat dan lembut
- Piyo-inspired dengan maskot minimal
- Navigasi baru: Rumah, Makan, Mood, Cerita, Koleksi
- Desktop dan mobile friendly

## Penyimpanan
Versi ini masih menggunakan localStorage.
Belum menggunakan Supabase.

## File utama
Upload semua file berikut ke root repository GitHub:

- index.html
- style.css
- app.js
- logo.svg
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

## Fitur yang tersedia
- Catatan makan
- Catatan mood
- Cerita harian
- Ringkasan koleksi sederhana
- Export backup JSON
- Import backup JSON
- Reset semua data lokal
- PWA dasar

## Langkah upload
1. Hapus file lama di repository jika perlu.
2. Upload semua file dari paket ini ke root repository.
3. Commit perubahan.
4. Tunggu GitHub Pages deploy ulang.
5. Buka website dan hard refresh jika perubahan belum muncul.
