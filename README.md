# Ruang Kecilku V4

Versi ini merapikan keseluruhan tema Piyo agar lebih konsisten di seluruh aplikasi.

Perubahan utama:

- logo tetap menggunakan ilustrasi Piyo
- mood sudah memakai sistem ekspresi Piyo yang seragam
- empty state memakai ilustrasi Piyo
- kartu ringkasan, quick action, dan badge halaman diselaraskan
- halaman Rumah, Makan, Mood, Cerita, dan Koleksi memakai bahasa visual yang sama
- kompatibel untuk desktop dan mobile
- data masih disimpan di localStorage

## File utama

- `index.html`
- `style.css`
- `app.js`
- `logo.svg`
- `manifest.webmanifest`
- `sw.js`
- `icon-192.png`
- `icon-512.png`

## Cara update GitHub Pages

1. Hapus file lama di repository.
2. Upload semua isi paket ini ke root repository.
3. Commit changes.
4. Tunggu GitHub Pages deploy ulang.
5. Lakukan hard refresh bila tampilan lama masih muncul.

## Catatan

Jika browser masih menampilkan versi lama:

- desktop: `Ctrl + F5`
- HP: tutup tab lalu buka ulang
- bila perlu hapus cache website
